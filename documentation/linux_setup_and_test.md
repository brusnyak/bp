Linux without per-OS hand-tuning. Windows 11 (CPU-only) and macOS (M1 Pro) are measured;
Linux is the remaining blank. This file is the plan and the lab sheet for that run.

filled in; the procedure in §2 was superseded mid-run by the `lite` one-command setup — the

## 2. Setup (measured run 1, 2026-09-28)

```bash
sudo apt-get install -y python3.12-venv ffmpeg libsndfile1 espeak-ng build-essential python3-dev
git clone -b <integration-tip> <repo-url> && cd bp
python3 scripts/setup.py --dev          # venv + deps + .env + certs + voices + whisper + MT/STT conversion
# .env is never in git -- add GOOGLE_CLIENT_ID locally (demo_preflight requires it)
# local-only voice assets (not in git since lite): sk_SK-personal-male-medium.onnx + .onnx.json,
# speaker_voices/ — copy them onto a demo machine by hand (setup falls back to generic voices without them)
```

`scripts/setup.py` supersedes the old manual steps (it also picks Python 3.12 — the pins
support 3.10–3.12). Measured: **250 s** wall for setup itself (cold pip + HF downloads +
all conversions) plus ~90 s apt + shallow clone on top.

GPU note: no change — ROCm still comes from the torch ROCm index and has no recorded
evidence on any machine (*Unknown* table below).
