Sending the translation into a meeting?
  1. Install a virtual audio cable: BlackHole (macOS) or VB-Cable (Windows).
  2. Reload this page, run the check, and choose the cable under Playback device.
  3. In the meeting software, choose the same cable as the microphone. Keep rehearsals on headphones.

Device names appear only after the browser has microphone permission. The page cannot tell whether the meeting is listening to the cable.
