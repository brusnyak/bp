    Get started

    Pick how you want to use it.

    1. Open the live page. A guest session starts by itself. No account.
    2. Pick the languages. The swap button turns the direction around.
    3. Press Start. Allow the microphone, use headphones. Stop ends capture and queued playback.
    Open the live page

    Needs Python 3.11 or 3.12 and ffmpeg

    git clone https://github.com/brusnyak/bp.git && cd bp
python3.11 scripts/setup.py --dev
make run

    Then open http://localhost:8000 in Chrome or Edge. Everything stays on your machine.

    About

    A bachelor’s thesis at STU FEI by Yegor Brusnyak: speech recognition, machine translation and speech synthesis chained into one live pipeline, built to break language barriers in online meetings.

    Not yet
    Many listeners in one room, large conferences.

    Questions

    Short answers, with the limits stated.

    Do I need an account?

    No. Open the live page and a guest session starts by itself. An account is only needed to record your own voice and keep it on the server under your name.

    Which languages work?

    Those listed on the live page, which reads them from this server. English to Slovak and Czech are the measured ones. Slovak and Czech recognition is the weaker half and is labelled experimental.

    Where does my audio go?

    To the machine that runs the translator. Run it yourself and nothing leaves your computer. On a shared server your audio goes to that server; it is processed, not stored, and logs hold no spoken text unless the operator turns session logs on.

    How does voice cloning work?

    You record a short sample and a cloning model synthesizes the translation in that voice. It needs a GPU and is a research feature: clones are not yet graded by listeners, and the default voice is a generic Piper voice.

    Can it handle a large conference?

    Not shown yet. One session at a time has been measured. Capacity has to be measured on the intended hardware before it is promised.
